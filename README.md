# CatatUang (Flutter)

CatatUang adalah aplikasi pencatatan keuangan yang saat ini menggunakan kode utama di folder `lib/` (Flutter).

## Jalankan Aplikasi

```bash
flutter pub get
flutter run
```

## Kualitas Kode

```bash
flutter analyze
flutter test
```

## Catatan Struktur

- `lib/` adalah implementasi utama aplikasi.
- `archive/legacy-react-web/` berisi kode React/Vite lama yang sudah diarsipkan.
